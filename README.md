\#\# Executive Summary  
OSIForge Pro is an engineering-grade sensor data simulation studio and compliance auditor implementing ASAM Open Simulation Interface (OSI v3.5.0) and ISO 23150:2021. It generates standardized GroundTruth and SensorData messages, manages ISO 8855 sensor mounting extrinsics, tracks perception object lifecycles with Bayesian probability distributions, and evaluates virtual HiL/SiL sensor interfaces against a 10-point normative compliance audit scorecard.
